## ‘기존’ 랭킹 시스템 현황

등급 체계 (29단계)

Bronze 4 → Bronze 1 → Silver 4 → ... → Diamond 1 → Master 1 →
Challenger 순으로 총점 0~100점 범위

![alt text](image.png)

- Commit + Challenge 합산 상한 35점

점수 반영 시점

- 출석/커뮤니티: 즉시 (이벤트 기반)
- 커밋/챌린지/순위: 매일 새벽 4시 배치

---

공유하는 구조가 가장 큰 특징이니 그 부분 염두에 두면 될 것 같습니다.

## ‘개선’ 랭킹 시스템

| 티어 | 상대평가 기준 | 절대점수 조건 |
| --- | --- | --- |
| Bronze | 상위 75~100% | - |
| Silver | 상위 50~75% | - |
| Gold | 상위 25~50% | - |
| Platinum | 상위 12~25% | - |
| Diamond | 상위 5~12% | 30점 이상 |
| Master | 상위 1~5% | 42점 이상 |
| Challenger | 상위 1% 이내 | 55점 이상 |

> 핵심: **점수는 상위 티어 해금 조건, 상대순위는 실제 진입 조건**
> 

---

## 운영 방식 요약

| 항목 | 방식 |
| --- | --- |
| 점수 반영 | 매일 새벽 4시 배치 |
| 티어 재배정 | 주 1회 정산 |
| Diamond 이상 승급 | 점수 + 순위 조건 충족 시 반영 |
| Diamond 이상 강등 | 7일 유예 후 반영 |
| 신규 유저 | 14~30일 Provisional 처리 |
| 활성 유저 기준 | 가입 14일 이후 + 최근 30일 내 활동 1회 이상 |
| 시즌 종료 후 | 이전 시즌 티어 기준 1~2티어 하향 Provisional 부여 |

## 1. 핵심 원칙

K-OSP 랭킹은 **상대평가 + 절대평가 혼합 방식**으로 운영한다.

> **점수는 상위 티어 해금 조건, 상대순위는 실제 진입 조건**
> 

---

## 2. 티어 구조

| 구간 | 평가 방식 | 설명 |
| --- | --- | --- |
| Bronze ~ Platinum | 상대평가 | 활성 유저 분포 기준으로 배정 |
| Diamond 이상 | 절대점수 + 상대순위 | 일정 점수 이상 + 상위 비율 충족 시 진입 |

---

## 3. 티어별 조건

| 티어 | 상대평가 기준 | 절대점수 조건 |
| --- | --- | --- |
| Bronze | 상위 75~100% | - |
| Silver | 상위 50~75% | - |
| Gold | 상위 25~50% | - |
| Platinum | 상위 12~25% | - |
| Diamond | 상위 5~12% | 총점 30점 이상 |
| Master | 상위 1~5% | 총점 42점 이상 |
| Challenger | 상위 1% 이내 | 총점 55점 이상 |

> Diamond 이상은 **절대점수 조건과 상대순위 조건을 모두 충족**해야 진입 가능하다.
> 

> Diamond 이상은 최대 12% 이내로 유지하되, 절대점수 조건을 충족한 사용자만 진입할 수 있다.
>

## 5. 절대점수 달성 기준

120일 시즌 기준으로 역산한 현실적 달성 시점이다.

| 티어 | 기준 점수 | 달성 시점 | 달성 조건 요약 |
| --- | --- | --- | --- |
| Diamond | 30점 | 시즌 초~중반 | 출석 + 커밋 + 커뮤니티 꾸준히 |
| Master | 42점 | 시즌 중반 | 위 조건 + 챌린지 또는 프로젝트 1개 |
| Challenger | 55점 | 시즌 60일차 전후 | 출석·커밋·챌린지·프로젝트 모두 적극 수행 |

---

## 6. 활성 유저 정의

상대평가 모수 산정 기준이므로 활성 유저 기준을 명확히 정의한다.

> 가입 후 14일이 지났고, 최근 30일 내 로그인 또는 커밋·챌린지·커뮤니티 활동이 1회 이상 있는 사용자를 활성 유저로 정의한다.
> 

활성 유저 기준이 없으면 휴면·탈퇴 유저가 모수에 포함되어 Bronze~Gold 분포가 왜곡될 수 있다.

---

## 7. 운영 방식

| 항목 | 방식 |
| --- | --- |
| 점수 반영 | 매일 새벽 4시 배치 |
| Bronze~Platinum 티어 재배정 | 주 1회 정산 |
| Diamond 이상 승급 | 조건 충족 확인 후 주 1회 정산 시 반영 |
| Diamond 이상 강등 | 7일 유예 후 다음 정산 반영 |
| 신규 유저 | 14~30일 Provisional 처리 |
| 시즌 종료 후 | 이전 시즌 최종 티어 기준 1~2티어 하향된 Provisional 부여, 새 시즌 활동 점수 산정 후 정식 티어 재배정 |

> 상위 티어인 Diamond 이상 승급은 일반 티어와 동일하게 주 1회 정산으로 반영하되, 강등만 7일 유예를 적용한다.
>

## 8. LoL 레퍼런스

출처: esportstales.com, 2026년 6월 기준

LoL의 티어 분포처럼 **중간층을 두껍게 두고 상위 티어로 갈수록 인원이 줄어드는 구조**를 참고한다.

다만 K-OSP는 교육·프로젝트 기반 서비스이므로 Diamond 이상 비율은 LoL보다 완화하여 **최대 12% 이내**로 설정한다.

| LoL 방식 | K-OSP 적용 |
| --- | --- |
| 중간층인 Silver·Gold·Platinum에 64% 집중 | Bronze~Platinum에 전체 88% 수용 목표 |
| Diamond 이상 5% 미만으로 희소성 유지 | Diamond 이상 최대 12% 이내 유지 |
| 시즌 초 소프트 리셋 + 배치전 | 신규 유저 Provisional + 시즌 종료 후 소프트 리셋 |
| LP 강등전으로 강등 완충 | Diamond 이상 7일 유예 |

---

## 9. 유저 공지 문구안

> Bronze~Platinum 구간은 시즌 내 활성 사용자 분포를 기준으로 산정됩니다.
> 

> Diamond 이상 티어는 일정 활동 점수와 상대 순위 조건을 모두 충족해야 진입할 수 있습니다.
> 

> 신규 사용자는 일정 기간 Provisional 상태로 분류되며, 충분한 활동 데이터가 쌓인 이후 정식 티어가 부여됩니다.
>
