# 랭킹 시스템 현황 보고

> 작성일: 2026-08-31
> 목적: 사업단 보고용 — K-OSP 플랫폼 랭킹 시스템 기능 현황

---

## ① 랭킹 구성

K-OSP 플랫폼의 랭킹은 두 가지로 운영됩니다.

| 구분 | 설명 | 최대 점수 |
|------|------|---------|
| **시즌 랭킹** | 한 학기 동안의 플랫폼 활동 점수 합산 | 100점 |
| **GitHub 랭킹** | GitHub 계정의 전체 활동 이력 기반 별도 랭킹 | 9점 |

---

## ② 시즌 랭킹 점수 기준

> **현재 시즌:** 2026-1학기 (2026.03.02 ~ 2026.06.30) — 종료

### 점수 항목 요약

| 항목 | 단위 점수 | 비고 |
|------|---------|------|
| 출석 기본 | 0.01점 / 일 | 로그인 시 자동 지급 |
| 연속 접속 보너스 | 1 ~ 10점 | 7·30·50·100일 달성 시 일회성 지급 |
| GitHub 커밋 | 0.05점 / 건 | 하루 최대 3건 인정, 합산 상한 35점 |
| 챌린지 달성 | 0.25 ~ 2.8점 | 난이도에 따라 차등 지급, 커밋과 합산 35점 |
| 프로젝트 참여 | 레벨별 2 ~ 10점 + 역할 보너스 | 관리자가 등록·종료 처리 시 자동 지급, 최대 30점 |
| 게시글 작성 | 0.5점 / 건 | 최대 20건(10점)까지 인정 |

> 커밋 + 챌린지 합산 상한: **35점** / 전체 시즌 점수 상한: **100점**

### 시즌 티어 기준

시즌 종료 시 최종 점수 기준 백분위로 티어가 자동 부여됩니다.

| 티어 | 조건 |
|------|------|
| 챌린저 | 상위 20% + 총점 60점 이상 |
| 다이아 | 상위 20% (챌린저 미충족 시) |
| 플래티넘 | 상위 20~40% |
| 골드 | 상위 40~60% |
| 실버 | 상위 60~80% |
| 브론즈 | 하위 20% |

### 프로젝트 점수 상세

학생이 팀 프로젝트에 참여하면 관리자가 직접 등록하고, 종료 처리 시 점수가 자동 일괄 지급됩니다.

| 프로젝트 레벨 | 기본 점수 |
|------------|---------|
| Level 1 | 2점 |
| Level 2 | 4점 |
| Level 3 | 6점 |
| Level 4 | 8점 |
| Level 5 | 10점 |

역할별 추가 보너스: 팀장 +2점 / PM +1점 / 멤버 없음

> 예시: Level 3 프로젝트 팀장 → 6점 + 2점 = **8점**

**프로젝트 내용물은 현재 미정입니다.** 어떤 프로젝트를 대상으로 할 것인지, 레벨 기준을 어떻게 분류할 것인지 사업단과 협의 후 즉시 등록·운영 가능합니다.

## ⑤ GitHub 전체 랭킹 기준 (최대 9점)

시즌과 무관하게 GitHub에서 쌓아온 전체 활동 이력을 기반으로 별도 점수를 산정합니다.

| 항목 | 최대 점수 | 산정 기준 |
|------|---------|---------|
| 활동 수준 | 3점 | 커밋·PR 활동량 (3단계 구간) |
| 다양성 | 1점 | 기여한 저장소 수 (4단계 구간) |
| 영향력 | 5점 | 고스타 저장소, 오픈소스 기여, 이슈 해결 등 4개 항목 합산 |

**활동 수준 (최대 3점)**

| 점수 | 조건 |
|------|------|
| 3점 | 커밋 100건 이상 AND PR 20건 이상 |
| 2점 | 커밋 30건 이상 AND PR 5건 이상 |
| 1점 | 커밋 5건 이상 OR PR 1건 이상 |
| 0점 | 해당 없음 |

**다양성 (최대 1점)**

| 점수 | 조건 |
|------|------|
| 1.0점 | 기여 저장소 10개 이상 |
| 0.7점 | 기여 저장소 5~9개 |
| 0.4점 | 기여 저장소 2~4개 |
| 0.0점 | 기여 저장소 1개 이하 |

**영향력 (최대 5점)**

| 항목 | 점수 | 조건 |
|------|------|------|
| 고스타 저장소 보유 | 2점 | 내 저장소 중 스타 100개 이상 |
| 유명 오픈소스 기여 | 1.5점 | 스타 1,000개 이상 저장소에 기여 |
| 이슈 해결 기여 | 1점 | 내 PR로 이슈 10개 이상 해결 |
| 타인 저장소 기여 | 0.5점 | 타인 소유 저장소에 PR 기여 |

## ⑦ 사업단 협의 필요 사항

### GitHub 데이터 수집 복구
커밋 점수 및 GitHub 전체 랭킹이 일시 미작동 중입니다. 원인 파악 중이며, 복구 완료 시 과거 누락 데이터를 포함하여 재계산할 예정입니다.

### 프로젝트 내용물 확정
점수 지급 기능은 완성 상태이므로, 아래 사항이 확정되면 즉시 운영 적용 가능합니다.

| 확정 필요 사항 | 내용 |
|------------|------|
| 대상 프로젝트 목록 | 어떤 팀 프로젝트를 점수 대상으로 할 것인지 |
| 프로젝트 레벨 기준 | 각 프로젝트를 Level 1~5 중 어디에 해당시킬 것인지 |
| 참여자 역할 분류 기준 | 팀장·PM·멤버 구분 방식 |
