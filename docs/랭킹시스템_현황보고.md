## ① 랭킹 점수 기준

K-OSP 플랫폼의 랭킹은 **시즌 랭킹**과 **GitHub 전체 랭킹** 두 가지로 운영됩니다.

---

### 1-1. 시즌 랭킹 (최대 100점)

한 학기(시즌) 동안의 활동을 기준으로 산정하며, 아래 5개 항목의 합산 점수로 순위를 결정합니다.

#### 점수 획득표

| 항목 | 점수 | 획득 조건 | 비고 |
|------|------|---------|------|
| 출석 기본 | 0.01점 / 일 | 플랫폼 로그인 | 자동 지급 |
| 연속 접속 보너스 (7일) | 1점 | 7일 연속 로그인 달성 | 일회성 |
| 연속 접속 보너스 (30일) | 3점 | 30일 연속 로그인 달성 | 일회성 |
| 연속 접속 보너스 (50일) | 5점 | 50일 연속 로그인 달성 | 일회성 |
| 연속 접속 보너스 (100일) | 10점 | 100일 연속 로그인 달성 | 일회성 |
| GitHub 커밋 | 0.05점 / 건 | GitHub 커밋 활동 | 하루 최대 3건 인정 |
| 챌린지 달성 | 난이도별 0.25 ~ 2.8점 | 챌린지 조건 달성 | 커밋+챌린지 합산 최대 35점 |
| 프로젝트 참여 | 레벨별 2 ~ 10점 + 역할 보너스 | 관리자 지급 | 최대 30점 |
| 게시글 작성 | 0.5점 / 건 | 플랫폼 내 게시글 작성 | 최대 20건(10점) 인정 |

> 전체 시즌 랭킹 점수 상한: **100점**
> 커밋 + 챌린지 합산 상한: **35점**

#### (1) 출석 점수 (최대 약 20.8점)

플랫폼에 로그인하면 자동으로 출석 점수가 지급됩니다. 하루도 빠짐없이 꾸준히 접속한 학생에게 연속 접속 보너스가 추가 지급됩니다.

| 항목 | 점수 | 조건 |
|------|------|------|
| 기본 출석 | 0.01점 / 일 | 로그인 시 자동 부여 |
| 연속 접속 보너스 (7일) | 1점 | 7일 연속 달성 시 일회성 지급 |
| 연속 접속 보너스 (30일) | 3점 | 30일 연속 달성 시 일회성 지급 |
| 연속 접속 보너스 (50일) | 5점 | 50일 연속 달성 시 일회성 지급 |
| 연속 접속 보너스 (100일) | 10점 | 100일 연속 달성 시 일회성 지급 |

---

#### (2) 커밋 점수 (커밋·챌린지 합산 최대 35점)

학생의 GitHub 계정에서 코드 커밋 활동을 자동으로 수집하여 점수를 부여합니다.

| 항목 | 점수 | 조건 |
|------|------|------|
| GitHub 커밋 | 0.05점 / 건 | 하루 최대 3건까지 인정 |

- 수집은 매일 새벽 4시에 자동으로 이루어지며, 다음 날 점수에 반영됩니다.
- 자동 생성된 커밋(봇 커밋)은 점수 계산에서 제외됩니다.

#### (4) 프로젝트 점수 (최대 30점)

학생이 팀 프로젝트에 참여하면 관리자가 프로젝트를 등록하고 종료 처리 시 점수가 자동으로 일괄 지급됩니다. 점수는 프로젝트의 난이도(레벨)와 참여 역할에 따라 달라집니다.

| 프로젝트 레벨 | 기본 점수 |
|------------|---------|
| Level 1 | 2점 |
| Level 2 | 4점 |
| Level 3 | 6점 |
| Level 4 | 8점 |
| Level 5 | 10점 |

| 역할 | 추가 보너스 |
|------|---------|
| 팀장 | +2점 |
| PM | +1점 |
| 멤버 | 없음 |

> 예시: Level 3 프로젝트 팀장 참여 → 6점 + 2점 = **8점**

**프로젝트 내용물은 현재 미정입니다.** 사업단과의 협의를 통해 평가 기준 및 레벨 분류 체계를 확정할 예정입니다.

| 항목 | 점수 | 조건 |
|------|------|------|
| 게시글 작성 | 0.5점 / 건 | 최대 20건(10점)까지 인정 |

#### 시즌 티어 기준

시즌 최종 점수에 따라 아래 6단계 티어가 부여됩니다.

|------|------|
| 챌린저 | 상위 20% 이면서 총점 60점 이상 |

| 플래티넘 | 상위 20~40% |
| 골드 | 상위 40~60% |
| 실버 | 상위 60~80% |
| 브론즈 | 하위 20% |

### 1-2. GitHub 전체 랭킹 (최대 9점)

GitHub 계정의 전체 활동 이력을 기준으로 산정하는 별도 랭킹입니다. 시즌과 무관하게 GitHub에서 쌓아온 활동 전체를 반영합니다.

| 항목 | 최대 점수 | 기준 |
|------|---------|------|
| 활동 수준 | 3점 | 커밋·PR 활동량에 따라 0~3점 부여 |
| 다양성 | 1점 | 기여한 저장소 수에 따라 0~1점 부여 |
| 영향력 | 5점 | 스타 수, 오픈소스 기여 등 4개 항목 합산 |

**활동 수준 (최대 3점)**

| 점수 | 조건 |
|------|------|
| 3점 | 커밋 100건 이상 AND PR 20건 이상 |
| 2점 | 커밋 30건 이상 AND PR 5건 이상 |
| 1점 | 커밋 5건 이상 OR PR 1건 이상 |
| 0점 | 해당 없음 |

**다양성 (최대 1점)**

| 점수 | 조건 |
|------|------|
| 1.0점 | 기여 저장소 10개 이상 |
| 0.7점 | 기여 저장소 5~9개 |
| 0.4점 | 기여 저장소 2~4개 |
| 0.0점 | 기여 저장소 1개 이하 |

**영향력 (최대 5점)**

| 항목 | 점수 | 조건 |
|------|------|------|
| 고스타 저장소 보유 | 2점 | 내 저장소 중 스타 100개 이상 |
| 유명 오픈소스 기여 | 1.5점 | 스타 1,000개 이상 저장소에 기여 |
| 이슈 해결 기여 | 1점 | 내 PR로 이슈 10개 이상 해결 |
| 타인 저장소 기여 | 0.5점 | 타인 소유 저장소에 PR 기여 |

## ② 랭킹 항목별 구현 현황

### 2-2. GitHub 전체 랭킹 항목별 현황

| 항목 | 현재 작동 여부 | 추가 개발 필요 여부 | 비고 |
|------|--------------|-------------------|------|

## ③ 지원 필요사항

### 3-1. GitHub 데이터 수집 일시 중단

현재 GitHub 커밋 데이터 자동 수집에 이상이 발생하여 커밋 점수 및 GitHub 전체 랭킹 점수가 일시적으로 반영되지 않고 있습니다. 원인 파악 및 복구 작업을 진행 중이며, 복구 완료 즉시 과거 누락 데이터를 포함하여 재계산할 예정입니다.

### 3-2. 프로젝트 점수 내용물 미정

프로젝트 점수 지급 기능은 개발 완료되어 관리자가 직접 등록·운영할 수 있는 상태입니다. 다만 어떤 프로젝트를 대상으로, 어떤 기준(레벨)으로 분류할지에 대한 내용물이 아직 확정되지 않았습니다.

사업단과의 협의를 통해 아래 사항을 확정해주시면 즉시 운영 적용이 가능합니다.

| 확정 필요 사항 | 내용 |
|------------|------|
| 대상 프로젝트 목록 | 어떤 팀 프로젝트를 점수 대상으로 할 것인지 |
| 프로젝트 레벨 기준 | 각 프로젝트를 Level 1~5 중 어디에 해당시킬 것인지 |
| 참여자 역할 분류 기준 | 팀장·PM·멤버 구분 방식 |
